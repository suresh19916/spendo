# Spendo – Monthly Expense Tracker

Spendo is a modern, mobile-friendly expense tracking web application built using HTML, CSS, JavaScript, and Google Apps Script integration.

It helps users manage:
- Income
- Expenses
- Monthly budgets
- Spending categories
- Transaction history

with a clean and responsive UI.

---

# Features

## Authentication
- Secure login system
- Session-based authentication
- 30-minute session timeout
- Re-login support
- Logout functionality
- Persistent Apps Script URL storage

---

# Dashboard Features

- Net Balance Overview
- Total Income Tracking
- Total Expense Tracking

- Top Spending Categories
- Monthly Financial Summary
